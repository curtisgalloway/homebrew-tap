# Terms

- **Tap:** a Git repository containing Homebrew installation recipes.
- **Formula:** a Ruby recipe that tells Homebrew what to download and install.
- **Bottle:** an archive laid out for Homebrew to install directly into its package directory.
- **Sidecar:** a small file next to an archive; here it records the archive's SHA-256 checksum.
- **SHA-256:** a checksum used to detect changed or corrupted file contents.
- **Dispatch:** a GitHub event sent by one repository to start another repository's workflow.
- **Universal binary:** one macOS executable containing both Apple Silicon and Intel code.
- **Keychain:** macOS's protected credential store.
- **Secret Service:** the Linux desktop protocol for protected credential storage.
